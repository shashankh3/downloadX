downloadX Connector

Send downloads to the downloadX app running on this PC.

Connection

Usually http://127.0.0.1:9765. The native helper discovers the port automatically when the app is running.

Download interception

The browser copy is only cancelled after downloadX accepts the job, so nothing is lost when the app is closed.

Smaller video/audio responses are ignored. Playlists are always detected.

Smart rules

One host or wildcard per line. Subdomains match automatically.

Comma-separated extensions, without dots.

Windows only. English only. All traffic stays on this computer.
